under the hood

Five agents, one report.

Every submission passes through five separate agents before you see a number. Each one has a single job, so the final score is easy to trust and easy to check.

What happens when you click "Score this match"

1

The resume gets structured

The candidate's resume is read and turned into structured facts: contact details, skills, experience, education, certifications, and projects. Only what the resume actually says is kept.

2

The job description gets structured

The posting is turned into a short profile: title, seniority, must-have skills, nice-to-have skills, minimum experience, and responsibilities.

3

Evidence is pulled from the resume

For every requirement in the job description, the best-matching lines from the resume are retrieved, so the next step reasons from real text instead of guessing.

4

The gaps are reasoned out

Each requirement is marked matched, partial, or missing, with the evidence and a severity. This produces the score out of 100, the strengths, and the risks.

5

A coach turns gaps into a plan

The final agent writes priority actions, resume improvements, a learning plan, and interview prep for the candidate.

What it's built on

automation

The five agents run as one connected workflow, so a single submission triggers all of them in sequence automatically.

language model

Each agent calls the same AI model, so the job description and resume are judged by consistent standards.

record keeping

Results can optionally be logged to a spreadsheet, so nothing scored today is lost by tomorrow.

HireSmartly — built on n8n, Groq, and Google Sheets.
